# 🍔 SIAR - Sistema Integral de Administración para Restaurantes

Repositorio oficial para la documentación y entregas del proyecto **SIAR (Sistema Integral de Administración para Restaurantes)**, desarrollado para la asignatura de Ingeniería de Software.

---

## 📋 Descripción del Proyecto
SIAR es una solución tecnológica diseñada para optimizar los procesos operativos y de gestión dentro de un restaurante. El sistema centraliza el control de inventarios, la administración del menú, la gestión de pedidos de los clientes y la coordinación entre roles clave como administradores y meseros.
